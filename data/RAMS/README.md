# Roles Across Multiple Arguments (RAMS)

The RAMS data set is available here: https://nlp.jhu.edu/rams/


## Set up of the folder

The folder should be set up as follows:

```
.
└── data/
    └── RAMS/
        ├── data/
        │   ├── dev.jsonlines
        │   ├── test.jsonlines
        │   └── train.jsonlines
        ├── output/
        │   ├── split1/
        │   │   ├── dev.json
        │   │   ├── test.json
        │   │   └── train.json
        │   └── ...
        ├── splits/
        │   ├── split1/
        │   │   ├── dev.txt
        │   │   ├── test.txt
        │   │   └── train.txt
        │   └── ...
        └── README.md
```
